Hola profe! como esta? esta es la primera vez que agrego un repositorio a GitHub, espero pueda visualizar todo el proyecto.

El proyecto se trata de un analizador de partidas del League Of Legends, muestra info sobre el roster actual de jugadores, los cambios aplicados en el ultimo parche del juego, el tiempo restante para el próximo torneo etc.

Aun hay 2 ventanas que no llegue a desarrollar que son la de "Campeones" y "Historial de partidas"

Como no pude asistir a las 2 ultimas clases me informe con tutoriales de Youtube y también varias consultas a Claude

Por ahora los datos son inventados, pero mas adelante se puede vincular a la API de Riot Games y obtener los datos reales de cada jugador

Las ventanas son las siguientes

Login: Se solicita nombre de usuario y contraseña (Para acceder use "capitán" como usuario y "clash2026" como contraseña)

Inicio: Aparece la cuenta regresiva para el próximo torneo y las notas de parche

Roster: Aparecen todos los integrantes del equipo, mas adelante desarrollare la función para eliminar y agregar jugadores

Campeones: Aparecen los campeones mas usados por cada jugador, también datos sobre el desempeño

Historial: Lista de partidas del equipo completo, también con notas sobre el desempeño del mismo

Tambien cree un logo en .svg para el proyecto y lo transforme a .ico para que windows lo interprete y lo muestre en la barra de tareas
